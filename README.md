# Pretty Screentime

Welcome to the home of Pretty Screentime - a streamlined Chrome extension designed to empower digital wellbeing through meticulous screentime tracking. Developed with precision and simplicity in mind, this tool was originally crafted to assist a close circle of friends, including myself, to cultivate awareness around our digital habits within the Chrome browser environment.

## Features

- **Intuitive Interface**: Designed with ease-of-use at the forefront, providing a clear and engaging user experience.
- **Accurate Tracking**: Reliably logs screentime across various websites, offering valuable insights into online behavior.
- **Versatile Viewing**: Toggle between daily and weekly screentime analytics to gain comprehensive perspective.
- **Interactive Design**: Effortlessly select specific sites for detailed monitoring and analysis.
- **Elegant Visuals**: Utilizes a visually pleasing design language that enriches the overall user interaction.
